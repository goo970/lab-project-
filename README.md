# Maze Generation and Recursive Pathfinding

## Project Description
The program generates a random maze using recursive backtracking and finds a path from start to exit using recursive DFS.

## Functionality
- Random maze generation.
- Support for size adjustment (odd numbers).
- Search for a path from point S (start) to E (exit).
- Output a maze with a marked path.

## How to launch
1. Make sure that Python is installed.
2. Open the terminal and run:
   ```bash
   python maze.py
